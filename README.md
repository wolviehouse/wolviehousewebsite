## Deploy to Vercel
1. Create a new GitHub repository.
2. Unzip this package.
3. Upload all files and folders to the repository.
4. In Vercel choose Add New → Project.
5. Import the GitHub repository.
6. Vercel will detect Next.js automatically.
7. Click Deploy.
8. In Project → Settings → Domains add:
   wolviehouse.com
9. Add the DNS records Vercel shows you to Cloudflare.
