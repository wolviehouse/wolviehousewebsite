
# WOLVIE House — Final Site

## Included pages
- `/`
- `/trade`
- `/brands`
- `/community`
- `/consulting`
- `/ventures`
- `/contact`

No Updates or Journal pages are included.

## Brand system
- Warm greige: `#D9D2C5`
- Light neutral: `#E6E0D5`
- Charcoal: `#111111`
- Secondary text: `#6E685F`
- Wolvie Orange: `#FF5A2F`

## Site behavior
- Full-width sticky header
- Responsive dropdown navigation
- Scroll-reveal storytelling
- Editorial focus-area sections instead of cards/counters
- Separate clickable pages for each Wolvie area
- Reusable area-page component
- Geometric SVG monogram built into the site

## Replace your current GitHub project
1. Download and unzip this package.
2. In your existing GitHub repo, replace the old project files with the contents of this package.
3. Commit the changes to your main branch.
4. If the repo is already connected to Vercel, a new deployment should trigger automatically.
5. Otherwise import the repo into Vercel as a Next.js project.

## Local preview (optional)
```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.
